# house-watch

玉环市二手房价格监测工具。

## 做什么

从本地房产类公众号文章采集楼盘报价，解析出单价、面积、总价，按板块归类入库，
每日生成价格台账与走势图表，并自动同步到腾讯文档在线表格。

## 功能

- 采集：接收 FeedWe 的 Webhook 推送，落库公众号文章
- 解析：从文章正文提取楼盘名、单价、面积、总价、房龄
- 归类：按「楼盘 → 板块」显式查表为主，地名/路名为兜底
- 对比：与上一期、上月同期快照对比，计算环比与同比
- 出表：生成每日 Excel / CSV 台账
- 同步：通过腾讯文档开放平台 OpenAPI 写入在线表格
- 可视化：在在线表格中重建全市与各板块价格走势折线图
- 推送：汇总摘要推送到企业微信群机器人

## 技术栈

- Python 3（标准库 + 少量依赖）
- 腾讯文档开放平台 OAuth2 / OpenAPI
- 企业微信群机器人 Webhook
- 数据落 SQLite

## 数据流

公众号文章 → Webhook 网关 → 解析归类 → SQLite 快照
            → 台账 CSV → 在线表格 → 走势图表 → 企业微信摘要

## 说明

本项目仅用于企业内部房源价格监测，只写入自有文档，不读取任何他人数据。
